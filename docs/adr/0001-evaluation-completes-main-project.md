# 0001: การประเมินปิดสถานะโครงการหลัก

สถานะ: รับรอง

## บริบท

เดิมสถานะโครงการหลักคำนวณจากกิจกรรมหลัก ขณะที่การประเมินบันทึกเพียงคะแนนและเกรด จึงเกิดกรณีประเมินแล้วแต่ป้ายสถานะยังแสดง “ยังไม่เริ่ม” หรือ “กำลังดำเนินการ”

## การตัดสินใจ

การบันทึกผลประเมินโดยผู้ดูแลทำให้โครงการหลักเป็น `completed` ไม่ว่าคะแนนหรือความก้าวหน้าจะเท่าใด คะแนน 0 ยังถือว่าประเมินแล้ว เปอร์เซ็นต์ความก้าวหน้ายังคำนวณจากกิจกรรมหลัก และการซิงค์กิจกรรมจะไม่ทับสถานะของโครงการที่ประเมินแล้ว ผู้ดูแลสามารถเปลี่ยนสถานะภายหลังได้ และการประเมินซ้ำจะตั้งเป็น `completed` อีกครั้ง โครงการที่ `cancelled` ต้องเปิดดำเนินการใหม่ก่อนประเมิน

## ผลที่ตามมา

โครงการหลักอาจแสดง `completed` คู่กับความก้าวหน้าต่ำกว่า 100% ได้ หน้ารายการ Dashboard และรายงานต้องอ้างอิงสถานะที่เก็บในฐานข้อมูลเดียวกัน ข้อมูลประเมินเดิมที่ไม่ถูกยกเลิกต้องปรับสถานะครั้งเดียวพร้อม Audit Log
